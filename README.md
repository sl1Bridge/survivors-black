# survivors-black

Прототип игры на Godot 4.7.x. Целевая площадка — Steam. В текущей версии есть
перемещение, враги, автоматический пистолет, здоровье, выпадения, уровни и HUD;
утверждённый объём прототипа описан в
[`docs/product/scope.md`](docs/product/scope.md).

## Запуск

Открой `project.godot` в Godot 4.7.x и запусти проект. Управление движением — WASD.
