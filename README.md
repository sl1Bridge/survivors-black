# survivors-black

Стартовый каркас игры на Godot 4.x. Целевая площадка — Steam. Игровая механика
пока не реализована; утверждённый объём первого прототипа описан в
[`docs/product/scope.md`](docs/product/scope.md).

## Запуск

Открой `project.godot` в Godot 4.x и запусти проект. Главная сцена пока пустая:
это проверка основы проекта, а не играбельная версия.
