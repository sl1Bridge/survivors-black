# survivors-black

Прототип игры на Godot 4.7.x. Целевая площадка — Steam. Текущая сборка включает
меню, переназначаемое управление, настройки разрешения/FPS, элитных врагов, волну
отталкивания, магнитный подбор и постоянные улучшения; утверждённый объём описан в
[`docs/product/scope.md`](docs/product/scope.md).

## Запуск

Открой `project.godot` в Godot 4.7.x и запусти проект — откроется главное меню.
Управление по умолчанию: WASD — движение, F — способность, Esc — пауза; всё можно
переназначить в настройках.
