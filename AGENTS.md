# AGENTS.md — постоянные правила для ИИ-агента

Этот файл — точка входа: прочитай его в начале любой задачи. Остальные документы — по необходимости, через `docs/INDEX.md`.

## Общение

- С владельцем проекта — на русском, по делу и честно.
- Держись согласованной задачи. Идеи в `docs/product/scope.md` и любые планы — НЕ разрешение на реализацию.

## Игровые решения

- Явно заданные и одобренные владельцем числа вноси сам. Новые или неоднозначные игровые решения — баланс, поведение, видимые игроку эффекты — не решай сам: предложи вариант и получи одобрение владельца.
- Перед изменением механики перечисли связанные системы из `docs/systems/INDEX.md` и комбинации, которые могут сломаться.
- Труднообратимое архитектурное решение — сначала ADR (`docs/architecture/decisions/`) и одобрение владельца.

## Проверки и отчётность

- Не выдавай незапущенную проверку за успешную. В отчёте указывай: что запускалось, что нет и почему, остаточные риски.
- Каждая исправленная воспроизводимая ошибка получает регрессионный тест.
- Перечень проверок и их статусы — `docs/workflow/testing.md`.

## Запрещено без явного одобрения владельца

- `git push`, публикация сборок и релизов.
- Подключение внешних и платных сервисов, установка плагинов и новых зависимостей.
- Изменение этого файла (`AGENTS.md`).

## Порядок поиска знаний по проекту

1. Этот файл.
2. `docs/INDEX.md` — какие документы существуют.
3. `docs/systems/INDEX.md` — реестр систем: зависимости, код, данные, тесты.
4. Страницы затронутых систем и их зависимостей.
5. Дальше по ссылкам внутри документов.

Ссылки не открываются автоматически — открывай перечисленные документы сам.

## Источники истины

- Замысел игры — `docs/product/vision.md`; текущий объём работ — `docs/product/scope.md`.
- Правила механик — страницы `docs/systems/`.
- Данные и числа — файлы данных (появятся после выбора движка; соглашения — `docs/workflow/data-conventions.md`).
- Алгоритмы и формулы в коде — сам код; документы их не переписывают.
- Решения — ADR; история — `CHANGELOG.md` (это журнал, а не спецификация).
