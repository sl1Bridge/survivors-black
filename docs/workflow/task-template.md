# Постановка задачи — шаблон

Заполняется перед началом работы. Если какой-то пункт не удаётся заполнить — это повод уточнить задачу у владельца, а не додумать самому.

От владельца достаточно простыми словами: цели, изменения для игрока, не-целей и критериев готовности. Технические поля (SYS-ID, пути, тесты) заполняет агент по индексам.

- **Цель:** что делаем и зачем.
- **Поведение игрока:** что изменится для игрока (если ничего — так и напиши).
- **Критерии готовности:** по каким признакам поймём, что задача сделана.
- **Не-цели:** что в задачу НЕ входит.
- **Затронутые системы:** SYS-ID из `../systems/INDEX.md` и их зависимости.
- **Проверки:** что будет запущено по завершении (см. `testing.md`).
- **Одобрения:** нужны ли решения владельца (баланс, видимый эффект, архитектура, права).
