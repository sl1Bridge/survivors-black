# Происхождение ассетов (asset provenance)

Для каждого нового ассета (изображение, звук, модель, анимация) фиксируется:

| Поле | Что писать |
|---|---|
| Источник / автор | Откуда взят или кем создан (генератор, художник, библиотека) |
| Модель и версия | Конкретное название и версия генеративной модели или инструмента |
| Prompt / seed | Промпт, негативный промпт, seed — для воспроизводимости |
| Постобработка | Что сделано после генерации (обрезка фона, ресайз и т. п.) |
| Права / лицензия | Условия использования; для коммерческого проекта — обязательно |
| Одобрение | Кем и когда ассет принят в игру |

Где хранить: рядом с ассетом в виде `<имя>.provenance.md` или единым журналом —
решение принимается, когда появится первый ассет и выбран движок.

Жёсткие правила:

- Секреты (API-ключи, токены) и веса моделей в Git не помещаются.
- Ассет без заполненных полей не интегрируется: визуальное и игровое решение утверждает владелец.
- Автоматическая проверка заполненности полей — статус «TBD» в `testing.md`.
