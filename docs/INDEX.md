# Каталог документов

Только навигация: что существует и зачем. Обновляется вручную при добавлении или переименовании страниц; автоматически пока НЕ проверяется.

| Документ | Назначение |
|---|---|
| `product/vision.md` | Замысел игры: аудитория, игровой цикл, столпы, не-цели |
| `product/scope.md` | Утверждённый объём работ и парковка идей |
| `systems/INDEX.md` | Реестр систем: SYS-ID, зависимости, код, данные, тесты |
| `systems/_template.md` | Шаблон страницы системы (разделы необязательны) |
| `architecture/decisions/_template.md` | Шаблон ADR |
| `workflow/agent-playbook.md` | Стандартный процесс выполнения задачи |
| `workflow/human-playbook.md` | Руководство для владельца игры (простым языком) |
| `workflow/task-template.md` | Формат постановки задачи |
| `workflow/testing.md` | Проверки и их статусы («описана / автоматизирована / TBD») |
| `workflow/asset-provenance.md` | Происхождение ассетов |
| `workflow/data-conventions.md` | Соглашения об ID и данных |

Постоянные правила для агента — в корневом `AGENTS.md`, сюда они не дублируются.
