# SYS-ARENA — Арена

## Поведение

Игровая область совпадает с видимой областью окна (viewport). Это временная
прямоугольная арена без препятствий и отдельной графики. Враги появляются в
случайных точках её края; игрок остаётся внутри арены.
События SYS-EVENTS используют ту же область: предметы появляются внутри viewport,
а комета пересекает арену по случайной траектории рядом с её центром.

## Взаимодействия и рискованные соседи

`SYS-PLAYER` ограничивает положение персонажа границами viewport, оставляя круг
целиком видимым. `SYS-ENEMIES` использует край той же области для появления врагов.
`SYS-VIDEO` меняет размер viewport; это меняет доступные границы и точки появления. Проверяй,
что спавн не происходит за пределами viewport, а комета пересекает видимую область.

## Тесты

Проверять, что персонаж не выходит за край при движении и после изменения размера
окна.
