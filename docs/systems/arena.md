# SYS-ARENA — Арена

## Поведение

В текущем прототипе игровая область совпадает с видимой областью окна (viewport).
Это временная прямоугольная арена без препятствий и отдельной графики.

## Взаимодействия и рискованные соседи

`SYS-PLAYER` ограничивает положение персонажа границами viewport, оставляя круг
целиком видимым. Изменение размера игрового окна меняет доступные границы.
Будущие системы столкновений и врагов должны использовать ту же игровую область.

## Тесты

Проверять, что персонаж не выходит за край при движении и после изменения размера
окна.
