# SYS-PLAYER — Персонаж игрока

## Поведение

Для первого прототипа персонаж перемещается в плоскости видом сверху клавишами
WASD со скоростью 240 px/s. Диагональное движение нормализовано и не быстрее
движения по одной оси. Персонаж появляется в центре viewport и не может выйти за
его границы. Белый круг радиусом 16 px — временная заглушка, не финальный арт.

## Входы и выходы

- Вход: действия `move_left`, `move_right`, `move_up`, `move_down` из InputMap.
- Выход: позиция персонажа в координатах viewport.

## Взаимодействия и рискованные соседи

`SYS-ARENA` задаёт прямоугольные границы движения. Будущая `SYS-COMBAT` выбирает
ближайшего врага; при движении персонажа ближайшая цель может меняться.

## Тесты

Проверять старт в центре, скорость движения по оси, нормализацию диагонали и
ограничение у краёв viewport.
