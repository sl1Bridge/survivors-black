# SYS-RUN — Игровой забег

## Поведение

Главная сцена запускается из меню и создаёт игрока с постоянными бонусами,
врагов, пистолет, инвентарь, выпадения, прокачку и HUD. При смерти игрока забег
останавливается; накопленное золото один раз сохраняется, а HUD предлагает
вернуться в меню. Там доступны улучшения и настройки. Босс пока не реализован.

## Взаимодействия и рискованные соседи

`SYS-RUN` связывает `SYS-ARENA`, `SYS-PLAYER`, `SYS-ENEMIES`, `SYS-COMBAT`,
`SYS-INVENTORY`, `SYS-PICKUPS`, `SYS-PROGRESSION`, `SYS-HUD`, `SYS-MENU`,
`SYS-META-PROGRESSION` и `SYS-SAVE`. Проверяй полный цикл: смерть врага → XP/золото
→ конец забега → однократное сохранение золота → меню → покупка → сохранение →
бонусы в следующем забеге. Возврат из забега в меню и запуск забега из меню —
намеренная двусторонняя навигация.

## Тесты

Проверять запуск меню и забега, смерть, однократное начисление золота, возврат в
меню и применение постоянных бонусов при следующем запуске.
