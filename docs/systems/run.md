# SYS-RUN — Игровой забег

## Поведение

Главная сцена создаёт игрока, врагов, пистолет, инвентарь, выпадения, прокачку и
HUD и связывает их сигналы. При смерти игрока забег останавливается, а HUD
показывает экран завершения. Перезапуск, босс и меню мета-прогрессии пока не
реализованы.

## Взаимодействия и рискованные соседи

`SYS-RUN` связывает `SYS-ARENA`, `SYS-PLAYER`, `SYS-ENEMIES`, `SYS-COMBAT`,
`SYS-INVENTORY`, `SYS-PICKUPS`, `SYS-PROGRESSION` и `SYS-HUD`. При изменении
сигналов или порядка инициализации проверяй полный путь: появление врага → выстрел
→ смерть → лут → XP/золото → HUD/уровень.

## Тесты

Проверять headless-запуск сцены и сквозное взаимодействие систем в тесте gameplay.
